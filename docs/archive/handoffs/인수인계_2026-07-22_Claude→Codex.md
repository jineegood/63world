## 3. 전투 연출 / 사운드

- **적 공격음 순서 교체**: 시전 알림은 합성 신호음, **명중(피해 로그) 시점에 적 공격 소리**. 투사체는 착탄 순간 재생.
- **투사체 타이밍**: 공격 선언이 아니라 실제 피해 로그 프레임에서 발사·명중 (코덱스 작업분 마무리)
- **신규 사운드 연결**: 막기 훈련(보호막 소리), 기도의 방벽(반사 발동 시), 암흑중첩 쌓임/틱, 기절(적·플레이어 공통), 무기 숙련 반사, 단단해지기(보호막 상승 시점)
- **원소 폭발 처형**: 타격 → 남은 체력 표시 → **별도 처형 순간**(1.7초, 치명타 팝업 + 강화 폭발 연출 + 처형음) → 사망
- **메테오 4타 연출**, **은총의 심판 투사체 제거**
- **로그 타이밍**: 스킬 시전 로그 +1초, 차지(최후의 심판) 시전 로그 +0.6초, **적 행동 로그 -40%**
- **총데미지 표기**: `🛡️ 보호막이 4을 막아냈다! 6의 피해를 받았다! (총 10의 데미지)`
- **흡혈 로그**: `좀비이(가) 체력을 N만큼 회복했다!`
- 빗나감 문구에서 "N번째" 제거

## 8. Codex가 주의할 점

1. **CLAUDE.md 규칙 유지**: `game.js`는 패치 체인이므로 반드시 **마지막(살아있는) 정의**를 수정. 직접 참조 바인딩(`addEventListener('click', 함수명)`) 함수를 삭제/이동하면 부팅 실패.
2. **파일 편집은 bash + python3 스크립트로** (데스크톱 편집 도구의 mount 동기화 지연 이슈).
3. **새 스크립트를 index.html에 추가하면** `tools/run-baseline.ps1`에도 `--check` 라인을 추가해야 `tests/baseline.test.mjs`가 통과한다.
4. **테스트가 옛 스펙을 단정하면** 기대값만 새 스펙으로 갱신하고 **구조적 단정은 약화하지 말 것**. 이번 세션에서 갱신한 기대값은 전부 스펙 변경에 따른 것이다.
5. **코스튬 외형을 추가할 때**는 `look.type`에 대응하는 드로잉 분기를 `drawHumanoid`(머리/옷/악세) 또는 `drawPlayerSprite`(오라)에 반드시 함께 구현할 것. 타입만 만들면 조용히 아무것도 안 그려진다.
6. **Supabase 배포**: `src/cloud-config.js`에 URL·anon 키를 채운 채로 GitHub에 푸시해야 배포본에서 동기화가 작동한다(anon 키는 공개 가능).
