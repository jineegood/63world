# 63월드 서버 보안 전환 체크리스트

이 문서는 새 서버 보안 방식을 실제 수업용 게임에 켜기 전에 확인할 항목을 정리한다.
2026-07-26 승인 후 Supabase migration과 Edge Function을 적용하고
`securityV2Enabled`, `serverAuthorityV3Enabled`를 `true`로 전환했다.

## 현재 코드로 준비된 것

- [x] 학생 성장 정보, 인벤토리, 장비, 스킬, 퀘스트, 환경설정을 분리해 저장하는 v3 기반
- [x] 학생이 다른 학생의 저장값을 직접 읽거나 수정하지 못하게 하는 권한 정책
- [x] 서버에서 캐릭터 생성·불러오기와 허용된 맵 이동만 처리하는 1단계 기능
- [x] 골드·빌딩 상점 구매 가격과 보유 화폐를 서버가 직접 확인
- [x] 일반 장비와 코스튬의 소유권·장착·해제를 서버가 직접 확인
- [x] 무기 강화 비용, 성공 확률, 등급 변화를 서버가 직접 계산
- [x] 전문화 선택 조건과 스킬 포인트·선행 스킬 조건을 서버가 직접 확인
- [x] 펫 소환 비용·랜덤 결과·소유권·동행 펫을 서버가 직접 확인
- [x] 같은 요청의 중복 실행과 다른 행동으로의 재사용 방지
- [x] 두 기기의 저장 순서가 엇갈리면 최신 서버 값으로 되돌리는 충돌 처리
- [x] 일반 몬스터의 문제 출제·채점, 명중·치명타·피해·회복·보호막·상태이상을 서버가 계산
- [x] 일반 몬스터의 경험치·골드·빌딩 보상과 사망 손실을 서버가 확정
- [x] 학생 브라우저가 교사용 문제집 정답을 내려받지 않는 전투 통신 경로
- [x] 전투 중 새로고침·중복 제출·두 기기 충돌 시 서버 전투를 다시 불러오는 처리
- [x] 기존 게임에는 영향을 주지 않는 비활성 전환 스위치

## 아직 남은 개발 단계

- [x] 3단계: 일반 전투 행동, 문제 출제·채점, 피해량, 몬스터 처치 보상을 서버 계산으로 변경
- [x] 3단계 확장: 엘리트 몬스터와 최종 보스의 전용 규칙·보상을 서버 계산으로 변경
- [x] 4단계: 퀘스트 수락·진행·완료와 보상을 서버 계산으로 변경
- [x] 5단계: PvP가 v3 능력치만 사용하고 승패를 서버에서 기록하도록 변경
- [ ] 기존 테스트 계정의 v3 캐릭터를 관리자 화면에서 명시적으로 초기화
- [ ] 기존 `player_profiles_v2.data`를 v3 성장 정보로 자동 복사하지 않는지 재확인

이동 좌표와 채팅·교실 내 실시간 위치 공유는 지금처럼 가볍게 유지한다. 따라서 서버 보안 계산을
늘려도 학생들이 서로 움직이는 모습은 계속 볼 수 있고, 이동할 때마다 무거운 DB 요청을 보내지 않는다.

## 전환 순서

1. 수업이 없는 점검 시간을 잡고 DB 백업과 기존 배포 버전을 보관한다.
2. `student-combat-v3` Edge Function을 배포하고 허용 주소를 설정한다. 아직 호출하지 않는다.
3. 승인된 Supabase migration을 번호 순서대로 적용한다. 이 단계부터 학생의 문제집 직접 읽기가 막히므로 수업 중에는 하면 안 된다.
4. 관리자 화면에서 테스트 계정의 v3 캐릭터를 초기화한다.
5. 남은 엘리트·퀘스트·PvP 단계까지 완료된 웹 버전에서 전환 스위치를 `true`로 바꿔 GitHub와 Vercel에 배포한다.
6. 교사 1명과 테스트 학생 2명으로 로그인, 상점, 장비, 강화, 스킬, 일반 전투, 오답, 사망, 재접속을 확인한다.
7. 엘리트·최종 보스, 퀘스트 전체 흐름, PvP, 두 기기 충돌, 28명 동시 접속을 차례로 확인한다.
8. Supabase 로그에서 오류·호출량·DB 사용량을 확인하고 이상이 없을 때만 학생 계정 사용을 시작한다.

## 문제가 생겼을 때

학생 수업을 시작하기 전에 문제가 발견되면 먼저 학생 접속을 닫는다. 문제집 읽기 권한을 제거한
migration까지 적용한 뒤에는 전환 스위치만 `false`로 되돌리면 기존 전투도 문제집을 못 읽어
작동하지 않는다. 따라서 준비해 둔 롤백 SQL로 학생의 기존 `workbooks` 읽기 정책을 복구하고,
이전 Vercel 버전과 `false` 스위치를 함께 배포해야 한다.
v3 진행값을 예전 v2 JSON 저장값으로 자동 복사하지 않는다. 이미 학생이 v3에서 플레이한 뒤라면
임의로 되돌리지 말고 문제를 수정한 다음 다시 검증한다.
