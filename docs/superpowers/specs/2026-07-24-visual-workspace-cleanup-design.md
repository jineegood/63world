# 63world 탐색기 화면 정리 설계

## 목적

새 프로젝트 복사본을 만들지 않고 현재 최신 프로젝트와 Git 연결을 그대로 유지한다.
파일 탐색기에서 보이는 항목만 줄여 사용자가 프로젝트 폴더를 편하게 열 수 있게 한다.

## 바깥 폴더 정리

그 안으로 이동한다.

- `.git-empty-backup-20260723`
- `.git-reconnect-temp-20260723`
- `63world-pre-git-reconnect-20260723.zip`
- `63world-pre-git-reconnect-20260723.zip.sha256.txt`

현재 최신 프로젝트인 `63world` 폴더는 이동하거나 복제하지 않는다.
`CLAUDE.md`는 향후 작업 규칙 참고를 위해 제자리에 두되 Windows 숨김 속성을 적용한다.

## 프로젝트 안쪽 화면 정리

파일이나 폴더를 이동하지 않고 다음 항목에 Windows 숨김 속성만 적용한다.

- 도구 상태: `.agents`, `.codex_work`, `.git`, `.superpowers`
- 설치·검사 자료: `node_modules`, `docs`, `tests`, `tools`
- 서버·보조 자료: `supabase`, `vendor`, `시트`, `작업자료`
- 관리 파일: `.gitignore`, `package.json`, `package-lock.json`, `README.md`, `schema.sql`, `인수인계.txt`

기본 탐색기 화면에는 앱의 주요 구성만 남는다.

- `assets`
- `data`
- `src`
- `game.js`
- `index.html`
- `style.css`

숨긴 항목은 삭제되지 않는다. 파일 탐색기에서 **숨긴 항목** 표시를 켜면 언제든 다시
볼 수 있고, Git·Codex·npm·Vercel의 파일 접근에는 영향을 주지 않는다.

## 안전 조건

- `63월드` 같은 두 번째 프로젝트 복사본을 만들지 않는다.
- 현재 `63world` 프로젝트와 `.git` 저장소를 이동하지 않는다.
- 어떤 파일도 삭제하지 않는다.
- 기존 `이전작업보관` 폴더나 같은 이름의 목적지가 있으면 덮어쓰지 않고 중단한다.
- 이동 전후 백업 항목의 파일 수와 크기를 비교한다.

## 확인 방법

1. 바깥 폴더에 `63world`와 `이전작업보관`만 일반 항목으로 보이는지 확인한다.
2. 네 개의 예전 백업 항목이 `이전작업보관` 안에 존재하는지 확인한다.
3. 지정한 기술 항목에 Windows 숨김 속성이 적용됐는지 확인한다.
4. Git 상태가 깨끗하고 원격 연결이 그대로인지 확인한다.
5. 전체 테스트를 실행해 앱 동작에 영향이 없는지 확인한다.
