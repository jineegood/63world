# 서버 권한 보스 전투 v3 구현 계획

목표는 보스방의 출신 지역, 보스 종류, 전투 결과와 최종 보스 포탈 해금을 브라우저가 아니라 서버가 확정하게 만드는 것이다.

## 1. 서버가 보스방 출신 지역을 기억

- `player_core_v3`에 `boss_origin_map`과 `final_boss_unlocked`를 추가한다.
- 일반 사냥터에서 `bossRoom`으로 들어갈 때 현재 지역을 출신 지역으로 저장한다.
- `bossRoom`에서는 저장된 출신 지역의 엘리트 보스만 시작할 수 있다.
- 보스방을 나가면 출신 지역으로만 돌아가고 최종 보스 임시 해금을 지운다.

## 2. 최종 보스 포탈을 서버가 판정

- 늪지 엘리트 좀비 승리 커밋에서만 `final_boss_unlocked`를 켠다.
- `finalBossRoom` 입장은 늪지 보스방이며 해금값이 켜진 경우에만 허용한다.
- 최종 보스방에서는 `final_teacher` 전투만 허용한다.
- 패배 시 마을로 보내면서 보스방 임시 상태를 모두 지운다.

## 3. 브라우저를 서버 결과에 연결

- 보스방 입장·퇴장과 최종 보스방 입장·퇴장을 서버 이동 성공 뒤에만 화면에 반영한다.
- 엘리트와 최종 보스를 서버 카탈로그 ID로 변환한다.
- 새로고침 뒤 서버 세션의 보스 ID에 맞는 화면 보스를 복원한다.
- 서버 승리 응답으로 늪지 최종 포탈 표시를 갱신한다.

## 4. 검증

- 다른 지역 엘리트 요청, 잠긴 최종 보스방 요청, 다른 보스 세션 덮어쓰기를 거부한다.
- 엘리트·최종 보스의 체력, 공격력, 보상과 지역별 문제 출제를 검사한다.
- 항복·만료·패배·재접속에서 HP와 보스방 상태가 되돌아가지 않는지 검사한다.
- 전체 자동검사 통과 전에는 `serverAuthorityV3Enabled`를 켜지 않는다.
